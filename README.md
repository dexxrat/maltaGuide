# MaltaGuide — офлайн аудиогид по Гозо, Комино и Мальте

MVP PWA: карта + гео-триггеры + озвучка через браузер. Без бэкенда, без ключей, полностью бесплатно.

## Как запустить локально

Любой статический сервер подойдёт (нужен именно HTTP, не `file://`, иначе service worker и geolocation не заработают):

```bash
# вариант 1: Python
python -m http.server 8765

# вариант 2: Node
npx serve .
```

Открой `http://localhost:8765` в браузере (на телефоне — через IP компьютера в той же Wi-Fi сети, либо после деплоя).

## Как тестировать без выезда на Мальту

Панель симулятора — инструмент только для разработки, обычный пользователь её никогда не видит (см. "Dev-режим" ниже). Чтобы её открыть при тестировании, добавь `?dev=1` к адресу, например `http://localhost:8765/?dev=1`.

1. Открой ссылку с `?dev=1` и нажми "Начать гид".
2. Внизу экрана появится кнопка "🛠 Симулятор GPS", разверни её.
3. Включи галочку "Режим симуляции" — реальный GPS будет игнорироваться.
4. Выбери точку в списке и нажми "Телепортироваться" — сработает так же, как если бы ты физически пришёл туда: покажется карточка с фото/текстом и запустится озвучка.
5. Радиус срабатывания можно менять прямо в панели (по умолчанию 150 м — GPS телефона в реальности гуляет ±20–50 м, меньше ставить не стоит).

## Dev-режим (`?dev=1`)

Без этого параметра в адресе панель симулятора GPS **полностью скрыта**, а режим симуляции принудительно выключен — даже если когда-то был сохранён в localStorage браузера. Это сделано специально: конечный пользователь (брат) не должен случайно наткнуться на переключатель и сломать себе реальный GPS. Обычная ссылка `https://dexxrat.github.io/maltaGuide/` всегда открывается в "боевом" режиме — с настоящей геолокацией.

## Что нужно сделать перед поездкой

1. **Точечно перепроверить 4 координаты.** Основные 10 точек уже геокодированы через OpenStreetMap Nominatim по реальным картографическим объектам (`"coordsVerified": true`) — это надёжнее прежних приблизительных координат "по памяти". Но у четырёх точек `"coordsVerified": false`, потому что найденная точка — это центр посёлка/района, а не конкретное место (см. `"coordsNote"` у каждой в `data/pois.json`):
   - `dwejra` — весь парк разбросан (Inland Sea, Blue Hole, Fungus Rock — разные точки), сейчас взято усреднённое место.
   - `marsalforn`, `marsaxlokk` — центр посёлка, не сама набережная/пляж.
   - Остальные 10 точек можно не трогать, но беглым взглядом на Google Maps по всем 14 всё равно стоит пройтись — координаты из OSM тоже не гарантия на 100%.
2. ~~Добавить настоящие фото.~~ Готово — все 14 точек теперь используют реальные фото с [Wikimedia Commons](https://commons.wikimedia.org) (свободные лицензии CC BY / CC BY-SA), лежат в `assets/photos/`, подключены в `data/pois.json` (`"photos"`) и в офлайн-кэш `sw.js`. Авторы указаны в [CREDITS.md](CREDITS.md) — файл нужен, лицензии этого требуют, не удаляй его при деплое.
   - Если захочешь заменить какое-то фото на своё — просто перезапиши файл в `assets/photos/<id>.jpg` тем же именем, менять `pois.json`/`sw.js` не придётся.
3. **Проверить голоса на телефоне брата.** Web Speech API берёт системные голоса устройства. На Android зайди в Настройки → Специальные возможности → Синтез речи → убедись, что установлены голоса для русского и английского и что нужный язык скачан для офлайн-использования (иначе без интернета голос может не звучать или звучать роботом через запасной голос).
4. **Проверить дату феста в Victoria** (см. план поездки, раздел 8) — не связано с приложением, но важно для маршрута.

## Деплой (бесплатно) — GitHub Pages

```bash
git init
git add .
git commit -m "MVP audio guide"
git branch -M main
git remote add origin https://github.com/<твой-юзернейм>/maltaGuide.git
git push -u origin main
```

Дальше на GitHub: Settings → Pages → Source: `main` branch, папка `/ (root)` → Save.
Через пару минут приложение будет по адресу `https://<твой-юзернейм>.github.io/maltaGuide/`.

Отправь эту ссылку на телефон — открыть в браузере и (по желанию) через меню браузера выбрать "Добавить на экран «Домой»", чтобы иконка была как у обычного приложения.

## Ограничения текущего MVP (сознательно не делали)

- Тайлы карты (OpenStreetMap) кэшируются только по мере просмотра — если открыть совсем новый участок карты без интернета, он не прогрузится. Данные точек, тексты и фото (при добавлении по инструкции выше) при этом всё равно будут офлайн.
- Нет построения маршрута между точками — просто карта с метками.
- Нет загрузки своих фото пользователем в приложении.
- Иконка PWA — SVG; на iOS для идеального значка на экране "Домой" лучше сделать PNG 180×180, но SVG тоже работает.

## Структура проекта

```
index.html          — разметка, стартовый экран, карточка гида, dev-панель
style.css            — стили, адаптив под телефон
app.js                — вся логика: карта, геолокация, симулятор, озвучка, i18n
data/pois.json        — список точек (координаты, категории, иконки)
data/i18n.json        — тексты гида и интерфейс на RU/EN
manifest.json         — PWA-манифест
sw.js                 — service worker для офлайн-кэша
assets/icon.svg       — иконка приложения
```
